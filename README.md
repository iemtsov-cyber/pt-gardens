# P.T. Gardens Hotel - GitHub Pages site

Static, bilingual (English/Russian) investment landing page prepared for:

`https://iemtsov-cyber.github.io/pt-gardens/`

## Structure

- `index.html` - page markup and bilingual content
- `styles.css` - responsive styling
- `script.js` - language switch, reveal effects and image lightbox
- `assets/images/` - optimized project imagery
- `assets/video/` - project video
- `.nojekyll` - keeps GitHub Pages from applying Jekyll processing

## Publish

1. Create a public repository named `pt-gardens` under `iemtsov-cyber`.
2. Put these files in the repository root on the `main` branch.
3. In GitHub: Settings -> Pages -> Build and deployment -> Deploy from a branch -> `main` / `(root)`.
4. The site will be available at `https://iemtsov-cyber.github.io/pt-gardens/` after GitHub Pages finishes deployment.

All asset paths are relative, so the site works correctly under the `/pt-gardens/` project path.
